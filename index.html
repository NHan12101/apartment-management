Giao diện đã chuyển sang React!

Tôi đã chuyển đổi toàn bộ mã nguồn giao diện sang ứng dụng React (sử dụng Vite làm công cụ build) nằm trong thư mục /frontend.

Để khởi chạy giao diện mới, bạn vui lòng chạy các lệnh sau trong terminal của bạn:

cd frontend
npm install
npm run dev

Sau đó mở đường dẫn hiển thị trên terminal (thường là http://localhost:3000) để truy cập hệ thống.
